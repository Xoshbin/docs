- [Calculator](/guide/features/calculator) — Math, units, currency & crypto, percentages, dates, world clocks, colors, and more, inline.
- [Clipboard History](/guide/features/clipboard-history) — Browse, filter, favorite, and paste past copies.
- [File Search](/guide/features/file-search) — Find any file by name, instantly, with a rich preview.
- [Notes](/guide/features/notes) — Instant Markdown notes, daily logs, and desktop stickies.
- [Snippets](/guide/features/snippets) — Text expansion: type a keyword, paste the full text.
- [Window Management](/guide/features/window-management) — Resize and arrange windows with layout presets.
- [Aliases & Shortcuts](/guide/features/aliases-and-shortcuts) — Custom triggers and global hotkeys for any command.
- [Portals](/guide/features/portals) — Save URLs as named launchers you can find by name.
- [Scripts](/guide/features/scripts) — Run shell scripts from watched folders.
- [Runs](/guide/features/runs) — Monitor, inspect, and manage active and recent background tasks.
- [AI & Agents](/guide/features/ai-and-agents) — Ask AI, build agents, choose providers, manage threads.
- [MCP](/guide/features/mcp) — Connect external tools to your agents.
- [Browser Integration](/guide/features/browser-integration) — Search bookmarks, history, and tabs.
- [Extensions](/guide/features/extensions) — Browse, install, and manage extensions from the store.
- [Screen OCR](/guide/features/screen-ocr) — Extract and copy text from any region of your screen with on-device recognition and secret redaction.
- [System Commands](/guide/features/system) — Fast power and session controls: Sleep, Lock Screen, Restart, Shut Down, and Log Out.
- [Walkthrough](/guide/features/walkthrough) — Short interactive tasks that tick themselves off as you actually use Asyar.
- [Usage Statistics](/guide/features/usage-stats) — Track your productivity, top commands, and estimated time saved.
- [Import from Raycast](/guide/features/raycast-import) — Bring snippets, quicklinks, and app hotkeys over in one click.
- [Migrating from Raycast](/guide/features/migrating-from-raycast) — Full migration guide, feature mapping, and FAQ.
