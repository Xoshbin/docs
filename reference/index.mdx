Information-oriented lookup material. Each page describes one thing precisely — open a reference page when you need to look something up, not to learn from scratch.

## Pages in this section

- [**Manifest**](/reference/manifest) — Every field in `manifest.json`, required and optional.
- [**CLI**](/reference/cli) — The `asyar` command-line tool: `validate`, `build`, `dev`, `link`.
- [**Permissions**](/reference/permissions) — Every permission string, what it unlocks, and what happens when one is missing.
- [**Actions**](/reference/actions) — The ⌘K Action Drawer: fields, context, categories, registration.
- [**Command Arguments**](/reference/command-arguments) — Inline chip-row inputs declared per command; collected before the command runs.
- [**Dynamic Commands**](/reference/dynamic-commands) — Runtime-registered commands for items whose set depends on the user's environment (Apple Shortcuts, SSH hosts, project paths, scripts in directories).
- [**Script Headers**](/reference/script-headers) — `# @asyar.*` directives for shell scripts discovered in user-configured directories: title, icon, arguments, mode (incl. live-ticking `inline`), refresh interval.
- [**Search bar accessory**](/reference/searchbar-accessory) — Per-command dropdown rendered in the top-right of the search bar while a view is active.
- [**Troubleshooting**](/reference/troubleshooting) — Symptoms, causes, and fixes.
- [**Extension types**](/reference/extension-types/index) — View / result / logic / theme, plus in-view search.
- [**Background scheduling**](/reference/background-scheduling) — Declarative recurring task execution via `schedule` in `manifest.json`.
- [**SDK**](/reference/sdk/index) — One page per service.
- [**Design system**](/reference/design-system/index) — Asyar's design language (Measure), CSS tokens, components, and built-in icons.
- [**Host Settings**](/reference/host-settings) — Custom application scan paths and system discovery.
